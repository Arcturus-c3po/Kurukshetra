# KURUKSHETRA — A Mahabharata-Inspired 3D Action-Adventure Game

## About the Game

**Kurukshetra** is a 3D action-adventure game developed using the Unity game engine, inspired by the legendary Indian epic, the *Mahabharata*. The project aims to bring India's rich mythology, history, and cultural heritage to life through an engaging interactive gaming experience.

Set in the legendary world of the Mahabharata, Kurukshetra combines action-oriented gameplay, combat mechanics, enemy AI, immersive environments, and animation systems to create an experience inspired by one of India's greatest epics.

Our vision is to make Indian mythology more accessible to modern audiences through interactive storytelling and gameplay while showcasing the potential of game development rooted in Indian culture.

## Key Features

- **3D Action-Adventure Gameplay:** An interactive gaming experience built around movement, exploration, and combat.
- **Combat System:** Gameplay mechanics involving weapons, attacks, and character health.
- **Enemy AI:** Intelligent enemy behaviour featuring detection, melee combat, ranged combat, and boss encounters.
- **Checkpoint System:** A system that allows players to resume gameplay from designated checkpoints.
- **Chariot Mechanics:** Gameplay elements inspired by the iconic chariots of the Mahabharata.
- **Immersive Environments:** Unity-based terrain, world design, and environmental elements inspired by the epic setting.
- **Animation System:** Character and gameplay animations designed to enhance immersion.
- **Cultural Inspiration:** A gaming experience rooted in Indian mythology and heritage.

## Technology Stack

- **Game Engine:** Unity
- **Programming Language:** C#
- **Development Environment:** Visual Studio
- **Version Control:** Git and GitHub
- **Core Systems:** Player movement, combat, enemy AI, checkpoints, health management, animations, and environment design.

## Project Objective

The objective of Kurukshetra is to explore how modern game development technologies can be used to represent Indian mythology and cultural heritage in an engaging digital format.

The project also serves as a practical demonstration of game development concepts, including gameplay programming, AI behaviour, level design, animation integration, and collaborative software development.

## Innovation & Vision

Kurukshetra aims to bridge the gap between India's rich mythological heritage and modern interactive entertainment. The project explores the potential of culturally inspired games to engage younger audiences, encourage interest in Indian epics, and create opportunities for original Indian game development.

The long-term vision is to evolve the project into a more complete gaming experience with expanded gameplay, improved visuals, deeper storytelling, and broader platform accessibility.

## Development

Kurukshetra is a collaborative game development project built using Unity. Development involves implementing gameplay systems, integrating assets and animations, designing environments, and managing source code through Git and GitHub.

The project was also developed in the context of the **Smart India Hackathon (SIH) 2025**, under the theme of creating innovative games inspired by India's civilization, history, and culture.
